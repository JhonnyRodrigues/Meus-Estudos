Engenharia de software
    Campo amplo que cobre todo o ciclo de vida do software.

Arquitetura de software
    Parte da engenharia responsável pelas decisões estruturais relevantes.

Design de software
    Decisões de organização e colaboração em nível mais detalhado.

Estrutura de pastas
    Apenas uma manifestação física dessas decisões.


Engenharia de software é o campo mais amplo. Ela abrange todo o processo de criação, evolução e operação de software, incluindo:
- levantamento e análise de requisitos;
- modelagem de negócio;
- arquitetura;
- design de software;
- programação;
- testes;
- segurança;
- implantação;
- manutenção;
- qualidade;
- gestão de configuração;
- processos e métodos de trabalho.
