Na Clean Architecture, o projeto é organizado em camadas. As dependências devem apontar das camadas externas para as internas:
Infrastructure
      ↓
Interface Adapters
      ↓
Application
      ↓
Domain


# Direção das dependências:
HTTP / Banco / Framework
          ↓
       Adapters
          ↓
      Application
          ↓
        Domain

Fluxo de uma requisição:
HTTP Request
     ↓
Router / Middleware
     ↓
Controller
     ↓
Request Model / Input DTO
     ↓
Use Case
     ↓
Contract
     ↓
Infrastructure
     ↓
Use Case
     ↓
Presenter
     ↓
HTTP Response
